# Generative Art Canvas

ブラウザで動くインタラクティブなジェネラティブアートです。マウスやタッチで粒子を操作できます。

## 使い方

`index.html` をブラウザで開くだけで動作します。サーバー不要です。

## コントロール

| コントロール | 説明 |
|---|---|
| パレット | 粒子の色テーマを切り替え |
| 粒子数 | 同時に表示する粒子の数（20〜300） |
| 軌跡 | 粒子が残す軌跡の長さ |
| サイズ | 粒子の大きさ |
| モード | 追尾 / 回転 / 爆発 / 波 |
| クリア | キャンバスをリセット |
| 保存 ↓ | 現在の状態をPNGで保存 |
</content>
</invoke>
